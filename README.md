# Below the Floorboards

A small, original browser game inspired by the base game *The Binding of Isaac: Rebirth*. Explore a generated set of connected rooms, fight in four directions, collect supplies and upgrades, defeat a boss, and descend again. The art is drawn in code and does not use assets from the original game.

## Play locally

Run `python3 -m http.server 8000 --bind 127.0.0.1` in this directory, then visit <http://127.0.0.1:8000/>. A keyboard is required for gameplay. Use the Game guide button for card, pill, and heart explanations; it pauses a run while open. WASD moves; the arrow keys fire; E places a bomb; Space uses the healing item when charged; Q consumes the held card or pill; P pauses. Only one card or pill can be held at once; walking over another swaps it with the held one. The pickup label identifies its effect. Clear a room to open its doors and charge the item. Treasure doors are free on the first floor and cost a key afterward; shops always cost a key. Walk over priced goods to buy them with coins. Double shot, piercing tears, and splash tears combine with each other and with damage and rate upgrades. Enter the hatch after a boss to descend. After defeating the final boss on Depths II, enter the glowing exit to win and unlock the optional Lantern start. Select it before a later run to begin with one soul heart and +25 movement speed. The unlock is stored in browser local storage; if storage is unavailable it lasts only for the current page session. The top-right miniature map shows discovered and adjacent rooms. The top-left heart display represents health in half-heart units internally.

## Research and scope

Rebirth is a top-down, randomly generated action-RPG shooter where items alter abilities and combinations, and each run has a new dungeon. The [official Steam description](https://store.steampowered.com/app/250900/) describes its large pool of items, bosses, enemies, seeded runs, challenges, co-op and unlocks; the [PlayStation announcement](https://blog.playstation.com/?p=139455) discusses the remake. The game here follows the basic loop, not the full rules or content.

This is **not a mechanically exact reproduction**. Layout generation, enemy behavior, collision, projectile physics, values, health and damage are approximations. It has four ordinary enemy types, four original bosses, a small random set of stat and projectile upgrades, one healing active item, basic pickups, one simple shop and one secret room per floor, and six floors. A run proceeds through Basement I–II, Caves I–II, and Depths I–II; enemy counts rise through the third floor and then level off, while boss health increases each floor. Caves add burrowers that cannot attack or be damaged while underground, and Depths add enemies that fire three-shot spreads. Bosses use radial, aimed spread, or alternating attacks; the final boss alternates a twelve-shot radial burst and a three-shot aimed spread. Cards are The Fool, The Lovers, and Death; pills are Full Health, Health Up, Health Down, and Speed Up. Keys unlock shops and later treasure rooms; coins buy shop goods. Projectile upgrades combine, but their effects and values are original approximations rather than the original item catalog. Bombs damage enemies, rocks and the player, and can reveal hidden passages when placed near the center of the correct wall. Each floor has one secret room, normally adjacent to as many ordinary rooms as the generated layout allows. Soul and black hearts protect red health first; depleting a black heart damages all room enemies. The health display caps containers plus protective hearts at 12 hearts. It does not implement super secret rooms and most special room types, most cards and pills, other health types, the original item catalog and its full synergy rules, the original characters and unlocks, seeded runs, original endings, challenges, controller support, co-op, or the original game's full roster, room layouts, progression and balancing. Pickups and upgrades are approximations. Pill effects are shown immediately instead of being unidentified until used, their values and generation are simplified, and Health Down cannot remove the last red container. Secret-room placement, contents, and door rules are simplified; black-heart damage and the health cap are approximations of the base rules rather than a complete implementation. There is no touch control or sound. The game does not save runs; only the Lantern completion unlock is stored when browser storage works.

The game is self-contained and uses a 2D canvas because the source gameplay is top-down. No build step or third-party runtime library is required. The chapter order is inspired by [Rebirth’s chapters](https://bindingofisaacrebirth.wiki.gg/wiki/Chapters); the enemies, bosses, six-floor ending, Lantern unlock, layouts, and combat values are original approximations; the original game has additional chapters, endings, unlocks, and branching progression. A Google Fonts stylesheet is optional; local fallbacks work offline.

Run focused rules tests with `node --test core.test.js`. With the local server running, visit `http://127.0.0.1:8000/tests/integration.html` for fixture-assisted browser checks covering secret-door bombing, heart depletion, selected consumables, the shop, projectile interaction, boss rewards and descent, chapter encounters, victory, the Lantern effect, death, and restart. The fixture adjusts game state and boss health; it is not an unaided playthrough.

Gameplay reference details were checked against the community-maintained [rooms](https://bindingofisaacrebirth.wiki.gg/wiki/Rooms), [hearts](https://bindingofisaacrebirth.wiki.gg/wiki/Hearts), and [cards](https://bindingofisaacrebirth.wiki.gg/wiki/Card) references, which cover later expansions as well as Rebirth. Only the selected effects described above are implemented here.

To test victory persistence in isolation, serve this directory on a separate loopback port, for example `python3 -m http.server 8001 --bind 127.0.0.1`, then open `http://127.0.0.1:8001/tests/persistence.html`. This fixture changes boss health, reloads the page, and restores the origin’s previous unlock value. It also simulates denied storage.
